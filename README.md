Screen Capture Tracker in Go is a beginner-friendly project built using the Go programming language. It is designed to help detect and track when a user takes a screenshot or starts screen recording on their system.

The main goal of this project is to help me (the developer) learn:

How to work with system-level events in Go

How to build simple tracking/logging tools

How to structure a Go application

How to create cross-platform Go programs (Linux, macOS, Windows)

As a learning project, it may start with basic logging features and improve step-by-step as I explore new Go concepts like goroutines, file handling, OS signals, and possibly desktop notifications or CLI interactions.
